# Current journeys

**Counting rule.** A navigation action opens a destination or a sheet, including selecting a different list or submitting a search to reach results. Typing, choosing a form value, and confirming a transaction are work and are listed separately. Automatic redirects or reloads are not extra taps. Counts start at the named screen. Scroll is noted separately. Desktop uses its sidebar; phone uses the bottom navigation and account menu.

## Employee on shift

| Start and intent | Current path and navigation actions | Work, outcome and way back |
|---|---|---|
| Inventory · find by name or SKU | Enter text → **Search** → item (**2**). From Home global search, **Search** → item is also **2**. | House espresso and COF-101 both found the record. Inventory rows already show quantity. Global search results show SKU and unit; open the item for its total. On-screen **Inventory** returns to the bare list. Global search stores its query in its URL. |
| Locations · find what is on a shelf | **Stockroom → Coffee shelf** (**2**); open **House espresso** for its total (**+1**). | Shelf contents appear above nested storage. **Parent location** goes to Stockroom. Starting from the item instead takes one shelf link to reach contents, but the same parent link still points to Stockroom. |
| Scan · identify a product | Type linked barcode → **Look up** (**1** in-place result); **Open item** or **Record usage** (**+1**). Camera entry substitutes **Start camera** and capture for typing. | Linked code returned House espresso. An unknown valid UPC told the employee to ask a manager. A printed QR opened the named record after sign-in in the existing browser scenario. Scan-result actions can open the quantity form directly. |
| Shelf showing House espresso · record usage | **Update** on the item row → **Record usage** (**2 sheets**). From item detail the matching shelf row has the same two-step path. | No duplicate shelf entry on either row path. For 1 kg on Coffee shelf, the status named the amount and path; the row refreshed. The notice did not state the new balance. Saving returns to the launching detail. |
| Item · waste or receive | **Update** on Coffee shelf → **Record waste** (**2**). **Receive stock** from the item header (**1**). | Entered 0.5 kg waste on the preselected shelf. For the ordinary receipt, selected Service shelf, entered 1 kg and saved. The single-stocked-shelf Brew scale also required **Update → Record usage** to use one unit. On an item-only scan with two stocked shelves the first available shelf was preselected. |
| Item · request stock and check it | **Request more** (**1**) → choose destination, enter requested quantity, **Submit request**. Return from detail via **Requests**; choose **Mine**, then the request (**2 more** from the list). | Submission lands on the request. A duplicate on the same shelf offers an explicit **Submit anyway**. From Home’s low-stock row, **Request** already supplies all three values. The employee Requests list initially opens **To receive**. |
| Requests · receive a partial shipment | From **To receive**, request row → **Record delivery** (**2**). | Enter only what arrived and save. The audit fixture retained 2.5 kg outstanding. The browser suite repeated delivery through fulfillment. **See stock history** opens the item top; on the audited phone History was below the fold. |

## Owner running the business

| Start and intent | Current path and navigation actions | Work, outcome and way back |
|---|---|---|
| Signed-in business chooser · start the day | Business name → **Home** (**2** to oversight). Visiting the organization root reaches Home automatically. | A new business gets setup guidance; the established audit business still showed four completed steps above work needing attention. The checklist can be hidden per browser. |
| Home · review a shortage | Scroll to **Low stock** → **Request** (**1**) or open the existing R-number (**1**). **See all** opens filtered Inventory. | Shortfall, item and shelf are prefilled. Saving a new request opens its detail. The list and detail are useful as-is once visible. |
| Home · approve less than requested | Scroll to the Requests card → pending request (**1**) → **Approve** (**+1 sheet**). Alternative from the persistent navigation: **Requests** → pending row (**2** to detail). | Change the approved amount and confirm. Employee can then record arrivals. Request detail shows each quantity separately. The on-screen **Requests** link goes to the role’s default list. |
| Item · transfer equipment and investigate | **Transfer** (**1 sheet**); choose destination, quantity and save. Inspect **Stock by location**, then scroll to **History**. From a receipt, **See stock history** takes **1** action plus scrolling. | Transferred one Brew scale from Stockroom › Coffee shelf to Coffee bar › Service shelf. The status named both locations. Existing inventory scenario also covered count adjustment and reversal. |
| First setup · location, item and label | From Locations: **Add location** → save room → **Add child location** → save shelf. From Inventory: **Add item** → save → **Add an expected location** → select shelf → **Add placement**. From item/location: **Create label** → choose layout → **Download PDF**. | Setup links mostly open lists. The checklist’s direct **Print labels** link skips target selection and opens an empty print screen. A normal record already supplies the target. Print output and QR resolution are separate steps. |
| People · invite, review access or recover an account | Desktop **People**, or phone account menu → **People** (**2**). **Invite staff** → choose role → **Create invitation**; invited employee signs in/registers and accepts. For recovery, member’s **Reset password** → **Create reset link**. | Owner shares the generated link. The suite verified membership restrictions, password change and old-session expiry. Role-change and access-removal confirmation controls were inspected in source. |
| Administration · investigate or export | Desktop sidebar → **Activity**, **Export data** or **Business settings** (**1**); phone account menu → destination (**2**). On Exports, **Download CSV** for the chosen dataset. | Opened all three as owner; the browser suite verified exported stock location, unit and quantity. Activity provides dated entries and resource links where available. Settings edits the displayed business name. |
